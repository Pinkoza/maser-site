Amendment drawings & restamping for a Calgary retail showroom

A marble and stone showroom in Calgary changed its layout after the permit drawings were issued — which meant the stamped set no longer matched the space. We prepared the amendment drawings and coordinated the review and restamping of the updated set.

Get a free quoteCall 778-803-5408

The situation

  • Retail showroom fit-out with a permitted drawing set already in place
  • The layout changed after issuance, so the drawings on file with the City no longer reflected the work
  • An amendment set had to be drawn, reviewed and restamped — a full resubmission would have cost weeks the opening schedule did not have

What we delivered

  • Updated amendment drawings reflecting the revised showroom layout
  • Coordination of the architectural review of the amended set
  • Restamping of the updated drawings so the permit file matched the built work
  • A single point of contact between the showroom's design team and the reviewing architect, start to finish

Why it matters

Amendments are where small commercial projects quietly go wrong: the space gets built one way, the stamped drawings say another, and the difference surfaces at inspection or lease renewal. Keeping the stamped set current is cheap insurance — and it is exactly the kind of drafting-plus-stamping package we run every week. See our permit drawings service and more recent project work.
