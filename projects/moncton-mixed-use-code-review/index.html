Building code review for a four-storey mixed-use building in Moncton

Before a four-storey mixed-use building in Moncton could go in for its building permit, its 35-page drawing set needed a full building code review. We reviewed every sheet against the National Building Code and returned a comment package the design team could build its revision on.

Get a free quoteCall 778-803-5408

The project

  • Four-storey mixed-use building: ground-floor commercial unit, residential lobby and a barrier-free studio suite, with three dwelling units per floor above — 10 units in total, about 11,000 sq ft
  • Development permit approved; the set was a development-permit level package being readied for building permit
  • Codes applied: National Building Code of Canada 2020 and National Energy Code 2020 as adopted in New Brunswick, including the provincial barrier-free design regulation

What the review found

  • 57 comments in total: 8 principal items and 49 additional items — 12 rated Critical
  • Exit discharge at ground level: both exit stairs funnelled to one exterior door, where the Code requires separate discharges at least 6 m apart
  • Exit separation on the upper floors below the required fraction of the floor diagonal
  • The 2-hour fire separation required between the commercial and residential occupancies not demonstrated
  • Sealed structural, mechanical, electrical, civil and fire protection drawings still outstanding

The outcome

The design team received the full comment package — every item referenced to the Code clause it comes from — so the set could be revised once, properly, instead of collecting the same comments from the City one round at a time. Catching the exit and fire-separation issues at review stage is far cheaper than catching them at permit review, when redesign delays the whole project.
